# LLMChatApp

Пример iOS-приложения на SwiftUI для локального взаимодействия с LLM на базе `llama.cpp`. Интерфейс состоит из трёх вкладок: обычный чат, конструктор задач ЕГЭ/ОГЭ и экран настроек с управлением моделями и параметрами генерации.

## Основные возможности

- Поддержка локальной генерации ответов через `llama.cpp` с настройкой `temperature` и `max_tokens`.
- Обычный чат с историей сообщений и индикатором генерации.
- «Спец. чат» с конструктором задач ЕГЭ/ОГЭ, генерацией оптимизированного промпта и пост-обработкой ответа модели.
- Экран настроек с загрузкой `.gguf` моделей с Hugging Face Hub, индикаторами прогресса и выбором активной модели.
- Сохранение настроек между запусками и выбор режима чата после инициализации модели.

## Структура проекта

```
LLMChatApp/
├─ LLMChatAppApp.swift      # Точка входа SwiftUI
├─ Models/                  # Модели данных (сообщения, элементы задач)
├─ Services/                # Работа с LLM, настройками и загрузкой моделей
├─ ViewModels/              # Логика экранов чата и конструктора задач
├─ Views/                   # SwiftUI-представления вкладок
└─ LlamaBridge/             # C++ враппер для llama.cpp
```

## Сборка

Откройте папку `LLMChatApp` в Xcode 15+ и убедитесь, что путь к `LLMChatApp-Bridging-Header.h` указан в настройках проекта. Для работы требуется подключённая сборка `llama.cpp` и доступная на устройстве `.gguf` модель.
